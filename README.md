# hatake-ame-radar（雨レーダー通知）

> **注意：雨の接近を保証するものではありません。**
> データの遅れや予報の外れで、通知が遅れたり、来なかったりすることがあります。大事な判断は、気象庁の公式の雨雲レーダーなども確認して行ってください。

気象庁の降水ナウキャストを見て、指定した地点に雨が近づいたらスマホに通知する Python スクリプトです（1地点版）。

## 仕組み

5分おきに次の3つの条件を調べ、すべて成立したときに [ntfy](https://ntfy.sh/) で通知します。

1. 地点から500m以内に、10分後の雨がある
2. 地点から500m〜3kmに、5分後の雨がある
3. 地点から3〜6kmに、現在の雨がある

現在の雨雲の位置を確認しながら、動きの予測は気象庁の予報に任せる、という考え方です。

## 必要なもの

- Python 3
- Pillow（`pip install pillow`）
- スマホの ntfy アプリ（通知を受け取るトピックを購読しておく）

## 使い方

1. `rain_radar_public.py` の「設定」を書き換えます。
   - `LAT` / `LON`：監視したい地点の緯度・経度
   - `LOCATION_NAME`：通知に表示する地点名
   - `NTFY_TOPIC`：ntfy のトピック名（他の人に推測されにくい長い文字列にしてください）
2. 実行します。

```
python rain_radar_public.py
```

## 主な設定

| 名前 | 内容 |
| --- | --- |
| `CHECK_INTERVAL` | チェック間隔（秒）。初期値は5分 |
| `NOTIFY_COOLDOWN` | 一度通知したあと、再通知しない時間（秒）。初期値は1時間 |
| `RAIN_PIXEL_THRESHOLD` | 雨と判定するピクセル数。誤報が多いときは増やす |

## 注意事項

- データの出典は気象庁です。公式に公開されたAPIではないため、仕様が変わると動かなくなることがあります。
- 気象庁のサーバーに負担をかけないよう、チェック間隔は5分より短くしないでください。
- 対象は日本周辺のみです。範囲外の座標では判定できません。
- 通知は1地点ごとに、雨の接近が確認できたときだけ出ます。
